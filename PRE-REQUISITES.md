# EduGenie – Pre-requisites

## Project Objective
EduGenie is a Google Gemini powered learning assistant that helps students understand academic topics through simple explanations, examples, summaries, and interactive AI assistance.

## Target Users
- School students
- College students
- Beginners
- Students preparing for examinations

## Technologies Required
- HTML
- CSS
- JavaScript
- Python
- FastAPI
- Google Gemini API
- GitHub

## Software Requirements
- Python 3.x
- VS Code or another code editor
- Web browser
- Git
- GitHub account

## AI Requirement
Google Gemini API will be used to provide AI-powered learning assistance.

## Basic System Flow
Student → Frontend → FastAPI Backend → Gemini API → AI Response → Student

## Prerequisite Checklist
- Python installed
- Git installed
- GitHub repository created
- Gemini API access obtained
- Project folder created
- Frontend environment prepared
- Backend environment prepared
